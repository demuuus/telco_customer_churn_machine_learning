01

ML Canvas

Fase: Ideation — living document, boleh direvisi
Validasi ide sebelum mulai coding. Isi tiap kotak secara singkat (bullet point, bukan paragraf panjang). Kalau ada kotak yang sulit dijawab, itu tandanya ide project perlu dipertajam dulu.
Value Proposition Untuk siapa? Masalah apa? Kenapa harus ML, bukan aturan manual?
Prediction Task Input → Output. Jenis task: klasifikasi / regresi / clustering?
Data Sources Sumber data, cara akses, siapa pemiliknya
Features Fitur yang tersedia saat prediksi dilakukan (bukan saat training)
Decisions Bagaimana hasil prediksi dipakai untuk mengambil keputusan?
Making Predictions Real-time atau batch? Seberapa sering?
Building Models Kapan model di-retrain? Siapa penanggung jawab?
Impact Simulation Bagaimana mengukur dampak nyata model (bukan cuma metrik teknis)?
Offline Evaluation Metrik yang dipakai untuk validasi sebelum "dianggap selesai", sesuai jenis task (mis. F1/recall untuk klasifikasi, RMSE untuk regresi, silhouette score untuk clustering) + baseline pembanding
Risk & Uncertainty Apa yang terjadi kalau prediksi model meleset? Kesalahan jenis apa yang paling mahal/berbahaya?
